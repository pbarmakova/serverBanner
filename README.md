
# serverBanner

**serverBanner** — это кроссплатформенный TCP‑сервер на Qt/C++ с графическим интерфейсом, предназначенный для обработки управляющих команд и передачи файлов по сети. Сервер позволяет наблюдать подключения клиентов в реальном времени, а также взаимодействовать с ними через JSON-команды.

---

## Возможности

- **Графический интерфейс (Qt)** — визуальное отображение подключений клиентов.
- **Логирование** — все действия фиксируются в файл `log.txt` и выводятся в консоль.
- **JSON-команды от клиентов**:
  - `PING` — проверка связи (ответ: PONG).
  - `EXIT` — завершить соединение с клиентом.
  - `STATUS` — получить текущее количество подключённых клиентов.
  - `GET_FILE` — отправка файла из папки `assets` клиенту.
- **Передача файлов** — сервер поддерживает отправку больших файлов по TCP в чанках (по 64 КБ).
- **Удобное расширение** — легко добавить новые команды.

## Быстрый старт

### 1. Зависимости

- Qt 5/6 (QtCore, QtNetwork, QtWidgets)
- C++17 или выше

### 2. Сборка и запуск

1. Соберите проект (через Qt Creator или вручную с помощью qmake/make).
2. В каталоге `src/build` появится исполняемый файл:
   - macOS/Linux: `BannerAdmin`
   - Windows: `BannerAdmin.exe`
3. Запустите файл — появится графический интерфейс для наблюдения подключённых клиентов.
4. Для передачи файлов клиентам используйте папку `src/build/assets`.


### 3. Использование

1. Запустите приложение — откроется окно с таблицей клиентов.
2. Сервер стартует на порту **1234** по адресу `localhost`.
3. Для теста подключитесь любым TCP‑клиентом (например, через `telnet` или своим Python-скриптом) и отправьте JSON-команду, например:
    ```json
    {"command": "PING"}
    ```

### 4. Передача файлов

Для передачи файла по запросу клиента:

- Поместите нужный файл в папку `assets` рядом с исполняемым файлом.
- Клиент должен отправить команду:
    ```json
    {"command": "GET_FILE", "filename": "example.zip"}
    ```
- Сервер отправит метаинформацию и сам файл по TCP.

## Протокол команд (JSON)

| Команда     | Параметры              | Описание                                      |
| ----------- | ---------------------- | --------------------------------------------- |
| `PING`      | —                      | Проверка связи, ответ: `PONG`                 |
| `EXIT`      | —                      | Завершить соединение                          |
| `STATUS`    | —                      | Количество подключённых клиентов              |
| `GET_FILE`  | `filename` (строка)    | Передать файл из папки `assets/`              |

---

## Логика работы

- **Server** — принимает подключения, парсит JSON, вызывает соответствующий обработчик из `CommandProcessor`.
- **Logger** — singleton для логирования всех событий (`log.txt`).
- **MainWindow** — GUI: показывает таблицу подключённых клиентов и их статус.
- **CommandProcessor** — содержит реализацию всех поддерживаемых команд.
